Knitter's Visual Swatch & Label Guide

How to Count Gauge Accurately

Knit a swatch at least 12×12 cm. Lay it completely flat on a table without stretching. Use a rigid ruler across the central 10 cm (4 inches).

Stitch Count = Count each "V" shape horizontally.
Row Count = Count each horizontal ridge / "V" column vertically.

Reading Yarn Skein Labels

  • Skein Symbol (#1 - #6): Craft Yarn Council weight standard.
  • Gauge Box (10×10 cm): Number at the bottom is stitches per 10cm; side is rows.
  • Needle Graphic: Recommended needle size. Knit brim with 0.5mm smaller needles.
